# Sikshya Global AI

A free starting point for learners to explore education, coding, and paths to earning. The site is a static, open source project; it does not currently provide an AI tutor, courses of its own, or job placement.

## Get started

Open `index.html` in a browser. No installation, build, account, or server is required. Swipe left or right on a touchscreen, use the section buttons, or use the previous/next buttons or arrow keys to navigate.

The interface supports English, Nepali, and Hindi. It starts in the browser's language when supported and otherwise uses English; the language selector can be used to change it. Linked resources are maintained by other organizations and may not be available in every language or region.

## Contributing translations

Add a language option in `index.html` and a matching set of translation keys in `app.js`. Use the language's standard language code and translate every key. Contributions of additional languages and locally relevant resources are welcome.
